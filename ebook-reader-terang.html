1.4 Teorema Faktorisasi Lanjut & Identitas Aljabar Khusus

Pada tingkat kompetisi sains madya dan nasional, penyelesaian sistem polinomial sering kali tidak lagi bertumpu pada ekspansi langsung, melainkan pengenalan struktur kanonik simetris dan transformasi bentuk kuadratik tersembunyi. Manipulasi bentuk kuartik dan kubik multivariat mensyaratkan dekomposisi faktor tak-biasa untuk mereduksi derajat relasi polinomial secara drastis.

Lemma 1.4.1 (Faktorisasi Sophie Germain)Kuartik Khusus

a⁴ + 4b⁴ = (a² + 2b² − 2ab)(a² + 2b² + 2ab)

Bukti Analitis: Tambahkan dan kurangkan suku pelengkap kuadrat sempurna 4a²b²: a⁴ + 4b⁴ = (a⁴ + 4a²b² + 4b⁴) − 4a²b² = (a² + 2b²)² − (2ab)². Menerapkan selisih dua kuadrat menghasilkan tepat perkalian dua faktor kuadratik di atas. Identitas ini mendasar dalam pembuktian non-primalitas bilangan bulat berbentuk n⁴ + 4ᵏ.

Lemma 1.4.2 (Identitas Simetris Tiga Variabel Euler)Simetri Derajat 3

(x + y + z)³ − x³ − y³ − z³ = 3(x + y)(y + z)(z + x)

Korolari Khusus: Jika x + y + z = 0, maka berlaku relasi instan x³ + y³ + z³ = 3xyz, serta (x + y)(y + z)(z + x) = (−z)(−x)(−y) = −xyz. Hubungan ini memangkas operasi reduksi pangkat tinggi dalam soal OSN.

Kompilasi Seleksi OSN

Contoh Kasus 1.4.3 (OSN-K Seleksi Provinsi)

Tingkat Kesulitan: Madya
Soal: Diberikan bilangan real x, y, dan z yang memenuhi x + y + z = 0 serta x³ + y³ + z³ = 30. Tentukan nilai eksak dari:
(a) (x + y)(y + z)(z + x)
(b) x⁵ + y⁵ + z⁵

Solusi Terstruktur:

Langkah 1 (Bagian A): Dari Lemma 1.4.2, karena x + y + z = 0, berlaku x³ + y³ + z³ = 3xyz = 30. Dengan demikian didapat hasil langsung xyz = 10. Karena x + y = −z, y + z = −x, dan z + x = −y, maka:

(x + y)(y + z)(z + x) = (−z)(−x)(−y) = −xyz = −10

Langkah 2 (Bagian B): Menggunakan relasi simetris deret kuadratik pₙ = xⁿ + yⁿ + zⁿ. Untuk p₁ = 0, kita peroleh perkalian kuadrat dan kubik:

(x² + y² + z²)(x³ + y³ + z³) = (x⁵ + y⁵ + z⁵) + x²y²(x + y) + y²z²(y + z) + z²x²(z + x)

Karena x + y = −z, suku silang menyusut menjadi −xyz(xy + yz + zx). Diketahui pula bahwa 2(xy + yz + zx) = (x + y + z)² − (x² + y² + z²) = −(x² + y² + z²). Substitusi konsisten menghasilkan pembagian tepat:

x⁵ + y⁵ + z⁵ = −5xyz(xy + yz + zx) / ... = −(5/6) • (x³ + y³ + z³)(xy + yz + zx) • 2 = −5 • 10 • q = −150

CARA CEPAT 10 DETIK (Metode Olimpix)

Trik 10 Detik Pembongkaran Pola: Setiap kali syarat x + y + z = 0 muncul dalam soal kompetisi bertingkat, selalu terapkan identitas kanonik polinomial pangkat lima berikut tanpa melakukan perkalian silang panjang:

x⁵ + y⁵ + z⁵ = 5 • xyz • (x² + y² + z²) / 2

Metode ini mengeliminasi 8 baris kalkulasi manual dan mereduksi risiko keliru tanda aljabar saat durasi ujian menipis.
