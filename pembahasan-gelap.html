SOAL NO. 14 MAT-OSNK-ALG-09
Skor Butir: -1 / +4

Diberikan barisan bilangan real positif (xₙ) dengan relasi rekursif:

xₙ₊₁ = xₙ / (1 + n · xₙ)

untuk setiap bilangan asli n ≥ 1. Jika diketahui suku pertama x₁ = 1, tentukan nilai dari jumlah tak hingga berikut:

Σ [xₙ · xₙ₊₁]  untuk  n = 1  sampai  ∞

LANGKAH BIMBINGAN BERTAHAP (Metode Olimpix) 3 Tahap Kunci
Tahap 1: Inversi Pecahan (Reciprocal Form)

Amati relasi rekursif xₙ₊₁ = xₙ / (1 + n·xₙ). Balik kedua ruas menjadi bentuk:

1/xₙ₊₁ = (1 + n·xₙ) / xₙ = 1/xₙ + n
Tahap 2: Eliminasi Bentuk Teleskopik

Perhatikan bahwa selisih kebalikan suku adalah: 1/xₙ₊₁ − 1/xₙ = n. Selanjutnya kalikan kedua ruas dengan suku xₙ · xₙ₊₁ sehingga diperoleh relasi:

xₙ − xₙ₊₁ = n · (xₙ · xₙ₊₁)
⇒ xₙ · xₙ₊₁ = (xₙ − xₙ₊₁) / n
Tahap 3: Jumlah Tak Hingga (Evaluasi Deret) done_all

Dengan deret teleskopik tereduksi, suku-suku saling mengeliminasi menyisakan suku terdepan dan batas limit ekor:

S_∞ = x₁ − lim (n→∞) xₙ₊₁ = 1 − 0 = 1
