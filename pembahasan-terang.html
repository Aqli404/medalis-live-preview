xₙ₊₁ = xₙ / (1 + n · xₙ)

LANGKAH BIMBINGAN BERTAHAP (Metode Olimpix)

1

Inversi Pecahan (Reciprocal Form)

Amati relasi rekursif xₙ₊₁ = xₙ / (1 + n·xₙ). Balik kedua ruas menjadi bentuk kebalikan pecahan:

1 / xₙ₊₁ = (1 + n·xₙ) / xₙ = (1 / xₙ) + n
2

Eliminasi Bentuk Teleskopik

Perhatikan bahwa selisih kebalikan suku menghasilkan deret aritmatika teratur:

(1 / xₙ₊₁) − (1 / xₙ) = n

Selanjutnya, kalikan kedua ruas dengan suku xₙ · xₙ₊₁ sehingga diperoleh formulasi langsung suku yang dicari:

xₙ − xₙ₊₁ = n · xₙ · xₙ₊₁  ⟹  xₙ · xₙ₊₁ = (xₙ − xₙ₊₁) / n
3

Jumlah Tak Hingga (Evaluasi Deret) verified

Dengan menguraikan deret teleskopik secara menyeluruh, seluruh suku tengah saling meniadakan dan menyisakan:

S∞ = x₁ − lim (n→∞) xₙ₊₁ = 1 − 0 = 1
